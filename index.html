Welcome to the Lab Guide

In this workshop you will build five labs on IBM watsonx Orchestrate — four specialised sub-agents and a master orchestrator that ties them all together. Follow each section in order.

Lab Overview

HR Helpdesk Agent System

This workshop focuses on an HR use-case. You will build a set of intelligent agents that help HR teams automate day-to-day work — from answering policy questions to managing emails and connecting to live data — then unify them under a single master agent.

Sub-agent 1

Policy RAG Agent

Answers questions by searching through internal HR and company policy documents using Retrieval-Augmented Generation.

Sub-agent 2

Web Search Agent

Finds up-to-date information from the internet — salary benchmarks, labour law updates, industry news, and more.

Sub-agent 3

Email Manager Agent

Reads and triages incoming HR emails, drafts replies, and sends outbound messages — all through a connected Gmail account.

Sub-agent 4

HR Analytics Agent

Converts natural language questions (Thai/English) into SQL queries against a live HR database — headcount, salaries, leave, and performance data.

HR Helpdesk Orchestrator

The HR Helpdesk Orchestrator receives every request from the HR admin and automatically routes it to the correct sub-agent. Admins interact with a single chat interface — the orchestrator handles the rest.

What You Will Build

  1. 1
    Policy RAG Agent

    Upload HR and company policy PDFs to a knowledge base. The agent uses RAG to answer employee and HR staff questions accurately from those documents.

  2. 2
    Web Search Agent

    Connect a live internet search tool so HR can ask about current regulations, market salary data, or any topic that requires up-to-date information.

  3. 3
    Email Manager Agent

    Deploy a pre-built Gmail agent that reads incoming HR emails, categorises them, drafts responses, and sends replies — saving hours of manual inbox management.

  4. 4
    HR Analytics Agent (Text-to-SQL)

    Connect a pre-imported Python tool to a SQLite HR database. The agent translates natural language questions into SQL and returns structured results about employees, salaries, leave, and performance.

  5. 5
    HR Helpdesk Orchestrator (Master Agent)

    Combine all four sub-agents into a single master agent. HR admins interact with one chat interface and the orchestrator automatically delegates to the right specialist agent.

Lab 1

HR Policy RAG Agent

Create an AI agent from scratch that can answer questions about company HR policies. You will upload three HR policy documents as a knowledge base, so the agent can retrieve and cite accurate information directly from those documents.

Step 1 — Create a New Agent

  1. 1
    Open the Agent Builder

    Click the hamburger menu (☰) in the top-left corner, then select Build.

  2. 2
    Create agent from scratch

    Click Create agent, then select Create from scratch.

  3. 3
    Name and describe your agent

    Enter the following details:

    Name hr_policy_agent
    Description HR Policy Assistant — answers questions about company HR policies including Privacy (HR-PL-001), IT Security (HR-IT-002), and Succession Planning (HR-TM-003).

Step 2 — Add the HR Policy Knowledge Base

  1. 4
    Scroll down to the Knowledge Base section

    In the agent editor, scroll down to find the Knowledge Base section and click Upload file.

  2. 5
    Upload the three HR policy PDFs

    Download and upload all three PDF files below:

    HR-PL-001

    นโยบายความเป็นส่วนตัว
    (Privacy Policy)

    ↓ Download PDF

    HR-IT-002

    นโยบายความมั่นคงปลอดภัยด้านเทคโนโลยีสารสนเทศ
    (IT Security Policy)

    ↓ Download PDF

    HR-TM-003

    นโยบายแผนการสืบทอดตำแหน่ง
    (Succession Planning Policy)

    ↓ Download PDF
  3. 6
    Fill in the knowledge name and description

    In the knowledge detail panel, enter the following:

    Knowledge name hr_policy_knowledge_base
    Description

    This knowledge base provides a comprehensive and authoritative reference for the company's HR policies and guidelines. It consolidates all essential rules, procedures, and best practices required for HR teams and employees to understand workplace regulations, data privacy, information security, and talent management.

    • Defines the company's privacy policy (HR-PL-001) covering employee personal data handling, data subject rights, consent management, and data retention procedures in compliance with applicable data protection regulations.
    • Contains the IT security policy (HR-IT-002) establishing information security standards, acceptable use guidelines, access control procedures, incident response protocols, and employees' responsibilities for protecting company data and systems.
    • Outlines the succession planning policy (HR-TM-003) describing the framework for identifying, developing, and retaining high-potential employees for critical roles, including talent assessment criteria, development pathways, and transition procedures.
    • Serves as the primary reference for HR staff and employees seeking guidance on HR compliance, data privacy rights, IT security obligations, and career development frameworks.

Step 3 — Set Agent Behaviour

  1. 6
    Add the agent instruction

    Scroll down to the Behaviour section and paste the following instruction:

    Agent instruction
    You are an HR Policy Assistant who specializes in helping HR staff and employees understand the company's human resources policies. You have access to three official HR policy documents in your knowledge base: the Privacy Policy (HR-PL-001), the IT Security Policy (HR-IT-002), and the Succession Planning Policy (HR-TM-003). Key responsibilities: - Answer questions about employee data privacy rights, personal data handling procedures, and consent management - Explain IT security obligations, acceptable use of company systems, access control, and incident reporting procedures - Provide guidance on the succession planning framework, talent identification criteria, and employee development pathways - Help employees understand their rights and responsibilities under each policy - Support HR administrators with policy interpretation and cross-policy clarifications Important guidelines: - All information should be based on the knowledge base documents - Always query the knowledge base before answering questions - Be professional, empathetic, and supportive in your responses - This agent primarily serves Thai-speaking HR staff and employees — most queries will be in Thai - Always respond in Thai by default; switch to English only if the user writes in English - Provide specific references to the relevant policy document and section when available - If information is not found in the knowledge base, clearly state this and suggest contacting the HR department directly - For sensitive topics (e.g., personal data breaches, disciplinary procedures), remind the user to follow the official escalation process - Always answer using the retrieved documents from the knowledge base

Try the following questions to verify the agent retrieves answers from each policy document.

Lab 2

Web Search Agent (Tavily MCP)

Build an agent that can search the internet in real time using the Tavily search tool connected via Model Context Protocol (MCP). This agent gives HR access to up-to-date labour law information, salary benchmarks, and current news.

Step 1 — Get Your Tavily API Key

  1. 1
    Visit the Tavily website and sign up

    Go to tavily.com, sign up or log in to your account.

  2. 2
    Copy your API key

    From your Tavily dashboard, copy your API key — you will need it in Step 3.

Step 2 — Create the Web Search Agent

  1. 3
    Open Agent Builder and create a new agent

    In watsonx Orchestrate, go to Agent Builder and click Create agent. Use the following details:

    Name tavily_search_agent
    Description Responsible for fetching external, real-time information from the internet. Use this agent for general world knowledge, news, current events, and facts that are completely unrelated to internal company documents, HR policies, or employee data.
  2. 4
    Click Create

    Confirm by clicking Create.

Step 3 — Connect the Tavily MCP Server

  1. 5
    Scroll to the Tools section and click Add tool +
  2. 6
    Choose MCP Server tools
  3. 7
    Click Add MCP Server in the top-right corner
  4. 8
    Enter the server name and connection command

    Set the server name to tavily-server and paste the command below, replacing <your-api-key> with your Tavily API key. Then click Connect and Done.

    MCP Server command
    npx -y mcp-remote https://mcp.tavily.com/mcp/?tavilyApiKey=<your-api-key>
  5. 9
    Activate tavily-mcp:tavily_search

    Find tavily-mcp:tavily_search in the tool list and toggle it on.

Step 4 — Set Agent Behaviour

  1. 10
    Scroll to the Behaviour section and add the instruction
    Agent instruction
    Always use the tavily search tools for every user question. Do not use your own training data and knowledge. This agent primarily serves Thai-speaking HR staff — most queries will be in Thai. Always respond in Thai by default; switch to English only if the user writes in English.

Step 5 — Test the Agent

Try the following questions to confirm the agent retrieves live data from the web.

General
  • เมืองหลวงของประเทศไทยคืออะไร
  • ช่วยลิสคำถามที่มักถูกถามตอนสัมภาษณ์งานหน่อย
HR Use-Case
  • What is the current minimum wage in Thailand? / ค่าแรงขั้นต่ำในประเทศไทยตอนนี้เท่าไหร่?
  • What are the public holidays in Thailand this year? / วันหยุดราชการในประเทศไทยปีนี้มีวันไหนบ้าง?
  • What is the current social security contribution rate? / อัตราเงินสมทบประกันสังคมปัจจุบันเท่าไหร่?
  • What are the requirements for a work permit for a foreign employee in Thailand? / เงื่อนไขการขอใบอนุญาตทำงาน (Work Permit) สำหรับพนักงานต่างชาติในไทยมีอะไรบ้าง?

HR Analytics Agent (Text-to-SQL)

Create an HR Analytics agent that translates natural language questions — in Thai or English — into SQL queries against a live SQLite HR database. The hr_query_tool has already been imported into the instance for you, so all you need to do is create the agent and connect the tool.

Step 1 — Create a New Agent

  1. 1
    Open the Agent Builder

    Click the hamburger menu (☰) in the top-left corner, then select Build.

  2. 2
    Create agent from scratch

    Click Create agent, then select Create from scratch.

  3. 3
    Name and describe your agent

    Enter the following details, then click Create:

    Name hr_analytics_agent
    Description Provides conversational HR analytics using natural language to SQL conversion. Can answer questions about employee headcount, salary bands, leave balances, performance ratings, and department comparisons in both Thai and English. Uses a SQLite database for data storage.

Step 2 — Add the HR Query Tool

Tool already imported

The hr_query_tool (including the HR SQLite database) has already been imported into this watsonx Orchestrate instance. You just need to connect it to your agent.

  1. 4
    Scroll down to the Tools section and click Add tool +

    In the agent editor, scroll down to the Tools section and click the Add tool + button.

  2. 5
    Select From this instance

    Choose From this instance (not MCP Server or upload) to browse tools already available in the shared instance.

  3. 6
    Find and add hr_query_tool

    Search for hr_query_tool in the tool list, select it, and click Add to attach it to your agent.

Step 3 — Set Agent Behaviour

  1. 7
    Scroll to the Behaviour section and paste the instruction
    Agent instruction
    You are an HR Analytics assistant for HR staff and managers. CRITICAL RULES FOR TOOL USAGE: 1. NEVER generate SQL queries yourself 2. ALWAYS pass the user's natural language query directly to hr_query_tool 3. The tool handles ALL SQL generation and database queries 4. Your role is to present the tool's results in a friendly, helpful way When the user asks a question: 1. Call hr_query_tool with the user's query as-is (Thai or English) 2. Wait for the tool to return results 3. Present the results in clear Markdown tables 4. Highlight important insights from the data 5. Provide actionable HR recommendations 6. Suggest relevant follow-up questions DO NOT: - Generate SQL queries yourself - Access the database directly - Modify the user's query before passing it to the tool - Make assumptions about specific employee data DO: - Pass natural language queries to the tool unchanged - Explain results clearly and professionally - Surface HR insights (e.g. open positions, high leave usage, top performers) - Respect employee data confidentiality in your tone Always be professional, data-driven, and respect HR confidentiality! This agent primarily serves Thai-speaking HR staff — most queries will be in Thai. Always respond in Thai by default; switch to English only if the user writes in English.

HR Helpdesk Master Orchestrator

Create the final master agent that ties all four sub-agents together. HR staff interact with this single agent and it automatically delegates every request to the correct specialist — RAG, web search, email, or HR analytics.

Step 1 — Create a New Agent

  1. 1
    Open the Agent Builder and create from scratch

    Click the hamburger menu (☰) → Build → Create agent → Create from scratch.

  2. 2
    Name and describe your agent

    Enter the following details, then click Create:

    Name hr_helpdesk_orchestrator
    Description Master HR Helpdesk Orchestrator — routes employee and HR team questions to the correct specialist sub-agent: Policy RAG for internal HR policy questions, Web Search for real-time external information, Email Manager for inbox and email tasks, and HR Analytics for employee data queries.

Step 2 — Add All Four Sub-agents as Collaborators

What are Collaborators?

Collaborators are other agents that this master agent can delegate tasks to. Add each of the four agents you built in Labs 1–4.

  1. 3
    Scroll down to the Collaborators section

    In the agent editor, scroll down until you see the Collaborators section (below the Tools section).

  2. 4
    Click Add collaborator + and add all four agents

    Click Add collaborator + and search for each agent by name. Add all four, one at a time:

    1 · hr_policy_agent

    Answers questions from the HR policy knowledge base (RAG).

    2 · tavily_search_agent

    Searches the internet for current labour law, salary benchmarks, and news.

    3 · Email Manager

    Reads, drafts, and sends emails through the connected Gmail account.

    4 · hr_analytics_agent

    Answers data questions (headcount, salary, leave, performance) via SQL.

Step 3 — Set Agent Behaviour

  1. 5
    Scroll to the Behaviour section and paste the instruction
    Agent instruction
    You are the HR Helpdesk Orchestrator — the single point of contact for all HR-related questions and tasks. You have four specialist sub-agents available as collaborators. Route every request to the correct one: 1. hr_policy_agent — Use for any question about internal company HR policies: privacy policy, IT security policy, succession planning policy, employee rights and responsibilities under those documents. 2. tavily_search_agent — Use for any question that requires current, real-world information from the internet: minimum wage rates, public holidays, labour law updates, market salary benchmarks, news, or anything NOT in internal documents. 3. Email Manager — Use for any task involving emails: reading inbox, listing emails, drafting a reply, or sending an email. 4. hr_analytics_agent — Use for any question about internal employee data: headcount, salary analysis, leave history, performance ratings, department comparisons. ROUTING RULES: - Always delegate to the most appropriate sub-agent — never answer from your own knowledge - If unsure, ask the user one clarifying question before routing - You may call multiple sub-agents in sequence if the request spans more than one domain - Always present results clearly and suggest a related follow-up question Respond in the same language as the user (Thai or English).
